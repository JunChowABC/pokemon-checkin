# 宠物打卡

**让现实里的每一点努力，都成为与宠物一起成长的日常。**

宠物打卡是一款把习惯打卡与宠物养成结合起来的像素风网页小游戏。读书、运动、整理房间，或完成一个自己的小目标，都可以换来金币与宠物经验；完成当天的必做任务，还能获得与新宠物相遇的机会。

从一只初始宠物、一间像素小屋开始，把每天完成的小事，慢慢变成热闹的宠物生活。

👉 **[点击开始游戏](https://junchowabc.github.io/pokemon-checkin/)**

## 怎么玩

1. **选择宠物**：挑选一只喜欢的初始宠物，开启你们的小屋生活。
2. **安排小目标**：设置任务内容、重复星期、必做或选做，以及奖励档位。
3. **完成现实任务**：在游戏中提交完成；需要家长确认的任务，通过后领取奖励。
4. **遇见新朋友**：当天至少有一项必做任务，且所有必做任务均已完成结算，就能获得当日相遇机会。按住捕捉球、瞄准并向上滑动，尝试捕捉新宠物。
5. **一起生活与成长**：领取每日补给，购买用品，喂食、洗澡、玩耍，陪伴伙伴升级与进化。

## 两种模式，各自成长

| | 成人版 | 儿童版 |
| --- | --- | --- |
| 适合谁 | 希望用养成游戏陪伴日常自律的玩家 | 一起建立生活习惯的孩子与家长 |
| 任务安排 | 自己创建与管理 | 家长安排，可选择是否需要确认 |
| 完成方式 | 自主点击完成，直接领取奖励 | 孩子提交，自主结算或由家长确认 |
| 管理入口 | 无需 PIN | 4 位家长 PIN |
| 其他功能 | 个人任务与养成 | 多个孩子独立小屋、简易/标准模式、儿童积分管理 |

成人版与儿童版的进度分别保存，切换版本不会相互覆盖。儿童版中，每位孩子的伙伴、任务、金币、积分和物品也各自独立。

## 小屋里有什么

- **丰富的宠物收集**：遇见不同种类的宠物，查看图鉴，为它们取昵称，选择自己的主伙伴。
- **可以互动的像素小屋**：左右拖动查看房间，看伙伴走动、停留和睡觉；轻点抚摸，或长按提起、重新摆放。
- **日常照顾**：关注饱食、清洁和心情，选择食物、沐浴露、玩具与零食；也支持批量照顾。
- **升级与进化**：完成任务、照顾伙伴获得经验；满足等级或道具条件后，亲自确认进化。
- **补给、商店与诊所**：领取日常照顾用品，使用金币购买补给与进化道具，照顾生病的伙伴。
- **任务历史月历**：按日期回看任务，以及未完成、待确认、已完成和已关闭状态。
- **儿童积分**：任务可在金币和经验之外设置积分奖励，家长可以分别管理每位孩子的积分余额。

伙伴的饱食、清洁和心情会随真实时间变化，离线时也会计算。记得回来看看它们。

## 开始使用

打开 **[游戏页面](https://junchowabc.github.io/pokemon-checkin/)**，选择成人版或儿童版，设置昵称并选择初始伙伴即可开始。儿童版首次创建时，还需由家长设置 PIN。

通过主页左上角的昵称入口，可以切换成人版与儿童版。游戏采用竖屏布局，支持鼠标和触屏操作。

## 存档与备份

**游戏进度自动保存在当前设备、浏览器和访问地址对应的本地存储中，没有账号或云端同步。**

- 换设备、换浏览器或换网址后，进度不会自动迁移。
- 清除浏览器网站数据可能丢失存档，请定期导出 JSON 备份。
- 成人版在「设置 → 存档备份」中操作；儿童版在「家长管理 → 存档备份」中操作。
- 两版备份需要分别导出，并在对应版本中导入。导入会替换该版本的现有进度，不影响另一版本。
- 儿童版备份包含全部孩子及家长 PIN，请妥善保管。
